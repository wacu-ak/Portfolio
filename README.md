# Personal Portfolio

A single-page portfolio website built with plain HTML, CSS, and JavaScript.

## Live Demo

https://wacu-ak.github.io/portfolio/


## Features

- Sticky header with links that scroll to each section
- About section with a short bio and an illustrated avatar
- Skills list generated from a JavaScript array using a loop
- Project cards generated from an array of objects using a loop
- Contact section with an email link and a GitHub link
- Responsive layout for phones, tablets, and desktops
- Automatic light and dark colour schemes
- Keyboard-visible focus styles and reduced-motion support

## Technologies Used

- HTML5
- CSS
- JavaScript (variables, arrays, objects, loops, DOM manipulation)
- GitHub Pages for hosting

## How to Run Locally

1. Download or clone this repository:
   ```bash
   git clone https://github.com/wacu-ak/portfolio.git
   ```
2. Open the `portfolio` folder.
3. Double-click `index.html` to open it in your browser.

No build step or dependencies are needed.

## What I Learned

I learned how to store data in arrays and objects and use loops to build page content instead of typing it by hand. I also practised keeping HTML, CSS, and JavaScript in separate files and making a layout that adapts to different screen sizes.
